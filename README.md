Open Payments provides a unified API platform that connects businesses to multiple banks, enabling payments, account data access, cross‑border transactions, and financial data aggregation. Their solution simplifies integration, reduces friction, and offers real‑time cash‑flow visibility, compliance with PSD2 and GDPR, and customizable branding for enterprises seeking to build modern financial services.

**Areas:** Company · Payments · Banking · Fintech

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Open Payments: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
